- Uma página só (`index.html`), com HTML, CSS e JavaScript puros, sem framework
- Responsiva, pensada primeiro para o celular
- Tema claro e escuro, seguindo a configuração do aparelho
- Os cards de projetos são gerados por JavaScript a partir de uma lista. Para adicionar um projeto, é só incluir um item no array `P`
- Botões de WhatsApp com mensagem já preenchida
- Publicado na Vercel: cada `git push` na `main` atualiza o site
